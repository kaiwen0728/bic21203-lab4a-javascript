Lab: Lab 4a – Client-Side Scripting (JavaScript)

**Lab Description**
This lab focuses on using JavaScript to create interactive web pages. 
It include three questions that shows:
- JavaScript functions
- event handling
- input calidation
- loops
- DOM manipulation

**How to run**
1. Download the project files from GitHub.
2. Open the folder for Question 1, Question 2 or Question 3.
3. Open the index.html file in a web browser.
4. Click the buttons and test the functions.


**Q1: Interactive Text Changer**
This question allows users to change a paragraph by clicking a button. The original message "Welcome to my website!" will changes to "Hello there!".
